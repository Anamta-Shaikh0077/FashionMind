
# FashionMind
### Luxury Fashion Intelligence Platform

FashionMind is a fashion analytics and data science platform.

It combines fashion design, retail analytics,
customer intelligence, and predictive modelling.

## Project Objectives

- Analyse fashion retail performance.
- Understand customer purchasing behaviour.
- Analyse fashion design attributes.
- Predict product demand.
- Build interactive data visualisations.

## Technologies

- Python
- SQL
- Pandas
- NumPy
- Power BI
- Scikit-learn
- Flask
- HTML, CSS and JavaScript
- Git and GitHub
